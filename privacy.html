1. General Information

LifeNifty Cloud Pipeline is an internal, personal-use automation tool operated solely on behalf of the official LifeNifty YouTube channel (@lifeniftymedia, Channel ID UCZ_BoVZfX-QOiRkvB95R_5A). This tool is not a public commercial service, SaaS product, or multi-tenant web application.

2. Google User Data Accessed & Scopes

The application interacts exclusively with the official YouTube Data API v3 using official OAuth 2.0 Authorization Code Flow for offline access. The following scopes are declared and utilized:

  • https://www.googleapis.com/auth/youtube.readonly: Used solely to verify the authenticated YouTube channel ID (UCZ_BoVZfX-QOiRkvB95R_5A) and inspect video processing statuses (SD/HD encoding, copyright status, privacy status) in read-only mode.
  • https://www.googleapis.com/auth/youtube.upload: Used solely to upload pre-approved video demonstrations strictly in private visibility.
  • https://www.googleapis.com/auth/youtube.force-ssl: Used solely to update metadata and configure scheduled release dates for pre-approved private video demonstrations.

3. Data Storage & Security

All sensitive credentials (client secrets and OAuth refresh tokens) are encrypted and stored securely within restricted GitHub Repository Secrets. No credential data is ever stored in public code, exposed in build artifacts, or accessible to third parties. All network operations utilize secure, encrypted HTTPS/TLS connections.

4. No Sharing or Sale of User Data

LifeNifty Media does not share, transfer, disclose, or sell Google user data or YouTube account data to any third party, advertising network, or external entity. Data accessed via Google APIs is used exclusively to operate the personal channel pipeline.

5. User Rights & Revocation

The channel owner retains complete control over application access at all times. Permissions can be viewed or revoked at any moment via the official Google Account Permissions Settings.
